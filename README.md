# NOBLES-GLOSS

Mobile-first 3D creation software with an original gothic-luxury identity inspired by Alcina Dimitrescu.

- **Current branch:** `DAIN`
- **Interface system:** DIMITTRESCUI
- **Reference-only:** SomaS3D may be consulted for ShofterUI ideas/code after checking exact files and licenses. This is an independent project.

## Principles
- Viewport-first, touch-friendly UI for phones and tablets.
- Editable scene and procedural material data, not only flattened images.
- Separate UI, geometry, rendering, materials, and import/export.
- Progressive, testable milestones; no premature claim of Blender parity.
- Review licenses, mobile support, and performance before adopting dependencies.
- Imported projects are untrusted; never execute embedded scripts automatically.
