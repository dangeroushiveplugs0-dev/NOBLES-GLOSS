# Roadmap

## Stage 0 — Foundation
- [x] Product identity, architecture and technology shortlist.
- [ ] Green clean-checkout Android CI; confirm minimum API/device matrix and license notices.

## Stage 1 — DIMITTRESCUI viewport
- [ ] Themed Android shell, actual renderer, camera navigation, grid, axes and test mesh.
- [ ] Contextual tools, collapsible panels, system insets and orientation handling.
- [ ] Real-device smoke tests.

## Stage 2 — Scene core
Versioned scene, stable IDs, transforms, hierarchy, commands, undo/redo, primitives, save/reopen, autosave/recovery.

## Stage 3 — Modeling/interchange
Editable vertices/edges/faces, transforms, extrude, inset, bevel, loop tools, subdivision, UVs/editor, GLB/glTF then OBJ, importer safeguards.

## Stage 4 — Materials
Typed editable graph, validation, PBR preview, baking/cache, searchable library, editable variants, wetness/organic/aging/optical/ornate recipes and quality tiers.

## Stage 5 — Sculpt/deformation
Sculpt brushes, spatial acceleration, modifiers, morphs and per-face attributes.

## Stage 6 — Rigging/animation
Skeletons, weights, pose tools, IK, morph animation and timeline.

## Stage 7 — Simulation/advanced import
Rigid bodies, cloth/soft-body experiments, caching and broader import support only after tests.

Every milestone: CI green, tests, license review, progress/errors for long jobs, touch/inset checks and explicit project migrations.
