# DIMITTRESCUI

Original interface inspired by the aristocratic gothic-luxury atmosphere associated with Alcina Dimitrescu. Do not copy game logos, artwork or proprietary UI assets.

Palette: near-black lacquer and charcoal; ivory/warm-stone text; deep burgundy selection; restrained muted brass accents. Preserve contrast and never rely on color alone for status.

## Layout
- Viewport is primary.
- Phone mode focuses one task with compact contextual controls.
- Tablet mode may place viewport beside inspector, hierarchy or node graph.
- Panels collapse/switch modes rather than stacking tiny desktop panels.
- Respect Android navigation/gesture insets.
- Comfortable separated touch targets; preserve state on rotation.

## Interaction
Camera and selection gestures must not conflict. Active modes should be obvious. Long jobs show progress and errors. Undo/redo maps to actual edits; recoverable failures preserve work.

## Material workspace
Preview and editable parameters together; node graph supports pan, zoom, fit, selection, socket connections and touch-sized controls. Library supports search, tags, favorites and editable variants for wetness, organic, aging, optical, ornate and stylized materials.

## Reuse boundary
ShofterUI from SomaS3D is reference-only. Inspect exact source, dependencies and licenses before copying.
